First npm release: `npx ghia-fluid-functionalism` downloads and opens the app on Apple Silicon macOS.

The styled components also ship as a library: `ghia-fluid-functionalism/<component>`, `/theme`, `/icon` and `/icons` are compiled Solid output with type declarations, with `@ghia/native`, `@ghia/solid`, `ghia-base-ui` and `solid-js` as exact peer dependencies.
